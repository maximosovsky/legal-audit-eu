# GDPR / ePrivacy lawyer-grade checklist

Not legal advice. Use this as a structured reference when completing the report.

## Transparency and notice — GDPR Arts. 12-14

- [ ] Controller identity and contact details.
- [ ] DPO contact where applicable.
- [ ] EU/UK representative where applicable.
- [ ] Purposes for each processing activity.
- [ ] Lawful basis for each purpose.
- [ ] Legitimate interests described where relied on.
- [ ] Categories of personal data and source where not direct.
- [ ] Recipients/categories of recipients and processors.
- [ ] International transfers and safeguards.
- [ ] Retention periods or criteria.
- [ ] Rights and request channel.
- [ ] Complaint authority.
- [ ] Consequences if required data is not provided.
- [ ] Automated decision-making/profiling details where applicable.
- [ ] Effective date/version.

## Rights — GDPR Arts. 15-22

- [ ] Access/export process.
- [ ] Rectification process.
- [ ] Erasure/account deletion process.
- [ ] Restriction process.
- [ ] Portability process.
- [ ] Objection process.
- [ ] Direct marketing objection honored immediately.
- [ ] Automated decision/profiling rights where relevant.
- [ ] Response timeframe and identity-verification method.

## Consent — GDPR Art. 7, Art. 8, Recital 32

- [ ] Freely given, specific, informed, unambiguous opt-in.
- [ ] Separate purposes are not bundled.
- [ ] No pre-ticked boxes.
- [ ] Withdrawal as easy as giving consent.
- [ ] Consent record includes timestamp, version, source, purposes.
- [ ] Children/parental-consent handling if relevant.

## Accountability and operations

- [ ] Art. 28 DPAs with processors.
- [ ] Art. 30 RoPA decision and record where required.
- [ ] Art. 32 security measures proportional to risk.
- [ ] Art. 33/34 breach notification workflow.
- [ ] Art. 35 DPIA screening and DPIA where required.
- [ ] Art. 37 DPO screening.
- [ ] Art. 27 EU representative screening for non-EU establishments.

## ePrivacy / PECR

- [ ] Strictly necessary cookies only before consent.
- [ ] Analytics/ads/pixels/session replay blocked until opt-in unless a specific regulator-supported exemption is documented.
- [ ] Reject all is as easy as accept all.
- [ ] Granular preferences and withdrawal path.
- [ ] Cookie table names provider, purpose, category, duration.
- [ ] Marketing email/SMS consent or valid soft opt-in, plus unsubscribe.

## Transfers

- [ ] Third countries and vendors identified.
- [ ] Adequacy/SCC/BCR/IDTA/Addendum basis identified.
- [ ] Transfer-impact/supplementary-safeguards review marked as owner/legal task where needed.
